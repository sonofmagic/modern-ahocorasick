# 扩展能力概览

已发布的 v3.2.0 通过可选入口提供折叠、可编辑词典和流式处理，没有运行时依赖。

这些是 `modern-ahocorasick` 的子路径，不是独立包。默认入口保持精确匹配，不加载可选折叠表或 Node 模块。
