# Cross-language Aho–Corasick source review

Baseline: `d50fcbfad26cc2a9b74c7d9f4379404a02b9df72`; retrieved 2026-09-22. [中文](cross-language.zh.md).

## Scope and method

This is a bounded survey, not a claim to have downloaded every implementation on the internet. GitHub discovery retrieved the first 50 results of each of two name/description searches, all 10 Ruby results and all 4 Swift results. Registry discovery covered npm (40 hits), crates.io (25), Maven (7), PyPI, NuGet and Go proxy. We pinned 27 source repositories and inspected three additional npm release tarballs. Exact revisions, dates, source links, test locations, registry evidence and gaps are in [sources.json](sources.json). A recent commit is an activity observation, not a maintenance or correctness guarantee; archived status is recorded separately.

Registry observations: Rust aho-corasick 1.1.5, daachorse 5.0.0; pyahocorasick 2.3.1, ahocorapy 1.8.0, ahocorasick-rs 1.0.3; Java org.ahocorasick 0.6.3; NuGet AhoCorasick 2.0.279. Source HEAD pins below must not be represented as these release artifacts. The two original npm comparisons remain fixed at @monyone/aho-corasick 1.5.10 and @tanishiking/aho-corasick 0.0.1.

Implementation families matter: ahocorasick_rs wraps BurntSushi, BlackGlory's npm package wraps daachorse (native/Cargo.toml); python-daachorse is also a wrapper. Vectorscan forks Hyperscan. Wikimedia's GitHub repository mirrors Gerrit. The Lua binding includes its own C++ builder/packed scanner. Ports inspired by Rust or Java remain separate implementations, but are not independent algorithm inventions. No third-party source code is copied into the library by this work.

- `lazy-aho-corasick@1.2.2`: object trie with failure/output arrays, startOnly and duplicate options. Borrow anchoring intent only; preserve our immutable, original-grapheme contract.
- `aho-corasick2@2.0.1`: ws-trie family release inventoried; no runtime claims or adoption based only on package metadata. Source-depth gap remains explicit.

## Complexity and semantic limits

For a classic sparse AC machine with constant-time edge lookup, scanning is O(n + z), where n is input units and z emitted occurrences; terminal output links avoid storing every suffix list. Hash/object lookup has runtime-dependent cost. Sorted compact transitions add edge-search cost; DAT provides an indexed edge probe but placement/build effort and unused slots depend on the dictionary. DFA/expanded suffix transitions trade memory/build work for fewer scan branches. Materialized global longest selection also pays sorting/overlap-selection costs and cannot promise bounded streaming. These statements describe structures, not a universal measured bound for every library above.

Byte libraries (Rust standard, many Go/C/PHP APIs) can match inside UTF-8 unless constrained. Python Unicode APIs generally use codepoints; Java/.NET char APIs use UTF-16 units. None is automatically equivalent to original grapheme boundaries. Python trie/map APIs may overwrite duplicate keys; Cloudflare Go returns unique IDs rather than every occurrence. Case-insensitive lower()/culture comparers are not full Unicode folding with expansion-aware original offsets. Only ASCII all-occurrence scenarios with unique patterns are suitable for a common runtime comparison here; other modes require separate groups.

## Capability decisions

| Status                            | Capabilities                                                                                                                                                                                                       | Reason                                                                                                                                         |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Already covered                   | overlaps, leftmost-first/longest, global longest-first, duplicate metadata, tokenize/replace, word rules, Unicode folding, dynamic snapshots, streaming/cancellation/previews, optional DAT, validated persistence | Keep public semantics and source-coordinate mapping; no compatibility shim                                                                     |
| First batch                       | validated original-text ranges and start anchoring; cached immutable compile statistics                                                                                                                            | Useful in editors, bounded searches and memory diagnosis without new runtime dependencies                                                      |
| First batch                       | contiguous DAT terminal offsets/IDs; immutable dispatch decision                                                                                                                                                   | Reduce JS allocations without changing result ownership/order                                                                                  |
| Experiment only until gate passes | first-symbol and 2-gram candidate filters                                                                                                                                                                          | Require ≥10% repeated target gain and no >5% reproducible main-scenario regression; all candidates must still use complete matching validation |
| Later candidates                  | bounded compilation, selectable dense shallow states/DFA, corpus-aware layout, portable binary persistence, explicit replacement priority                                                                          | Need memory/build budgets, versioned formats, workloads and separate API design                                                                |
| Not applicable this round         | SIMD/native bindings, WASM, mutable returned match pools, generic symbol streams, language collation/tolerant moderation, regex databases, queue-microtask                                                         | Conflict with scope or need a different matching contract                                                                                      |

Range filtering must precede overlap selection, and whole-word/constructor boundaries must inspect the full original input. Anchoring means start of the requested span. Full folding accepts only complete original graphemes (ß→ss cannot expose half an expansion). Statistics distinguish original graphemes from folded codepoints and TypedArray storage from total heap. Streams reject offline range options.

## Papers and primary documentation
